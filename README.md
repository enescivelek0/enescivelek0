## 📌 Genel Bakış

Ölçeklenebilir, yüksek performanslı ve sürdürülebilir kurumsal yazılım sistemleri geliştirmeye odaklanmış bir **Software Developer & Solution Architect**'im. **Clean Architecture**, **SOLID** ve **Domain-Driven Design** prensipleriyle teknik borcu minimize eden modern mimariler inşa ediyorum.

- 🔭 **Aktif Roller:** **Simur Digital** bünyesinde Web Geliştirme & **Upwork (Global)** üzerinde Freelance .NET Developer.
- 💼 **Önceki Deneyimler:** **Allify** (CRM Uzmanı) & **Pavo Group** (Yazılım Stajyeri - Savunma Sanayii / C#).
- 🎓 **Eğitim:** İstanbul Gedik Üniversitesi — Bilgisayar Programcılığı.
- 🎯 **Odak Alanları:** Enterprise .NET, RESTful API Mimarileri, Modern React/Next.js ve WordPress ekosistemi.
